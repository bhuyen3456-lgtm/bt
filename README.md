# Chương trình biểu đồ sinh viên nam nữ

1. Kích hoạt môi trường ảo:
   ```bash
   cd /home/huyen/demo
   . kiemtra/bin/activate
   ```
2. Chạy app:
   ```bash
   python app.py
   ```
3. Mở trình duyệt và truy cập:
   ```text
   http://127.0.0.1:5000/
   ```

Ứng dụng cho phép nhập số sinh viên nam và nữ và hiển thị biểu đồ cột tương ứng.
